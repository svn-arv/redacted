Nobody has to run a dangerous command.

The model is smart enough not to cat .env. That was never the way keys get in.

They ride along in ordinary output.

A committed key in git diff. A token in a log line. A stack trace that dumps the environment on its way out.

Some commands exist to print them.

heroku config, kubectl get secret, aws secretsmanager get-secret-value. Running them is the job, not a mistake.

Command guards read the wrong thing.

Deny lists and model judgment inspect the command string. An npm script, a make target, or a proxy CLI changes the string. The output is unchanged.

Once a secret is in context it is in the transcript on disk and in every request that follows. redacted does not judge commands. It scrubs the output, whatever produced it.

Three tiers, most precise first.

Each tag names the pattern that matched. An entropy-only guess prints without a name, so you can tell the two apart.

34 vendor signatures

Provider patterns

AWS, GitHub, Stripe, OpenAI, Anthropic, Slack, Twilio and more, matched on their exact key shape. Near-zero false positives.

22 credential keywords

Named keys

Any variable whose name contains SECRET, TOKEN, PASSWORD, API_KEY and the rest. Works in env files, shell exports, and YAML.

3.5 bits per character

Entropy scorer

Unknown keys whose value runs 16 to 128 characters, mixes case with digits, and scores above that threshold. Catches what no signature names.

The signature list.

Hover or tap a block to reveal it.

What it will not do.

Reach the network

A single Go binary that runs on your machine. No calls out, no telemetry, no account.

Fail open

If the hook errors, the output is withheld rather than passed through raw.

Store a value

Stats keep a timestamp, the tool name, and per-pattern counts. Never the matched text.

Leave you guessing

The last four characters stay, so the two rotated AWS keys above read as ...0001 and ...0002 without exposing either.

Install, then init.

One command registers the PostToolUse hook. Safe to run again at any time.
